# DevScout Cleaner

DevScout Cleaner 是一款面向 Windows 的本地 GUI 清理工具。它可以围绕一个软件安装目录，检查目录占用情况、搜索可能关联的注册表项，并在用户确认后清理文件夹和选中的注册表项。

它适合处理卸载残留、软件目录无法删除、程序已经卸载但注册表仍保留路径记录等场景。所有扫描和清理都在本机完成，不上传文件夹内容，也不依赖云端服务。

## 主要功能

- **文件夹拖放**：从 Windows 文件管理器拖入目录，自动填入路径并清空上一次的扫描结果。
- **目录概览**：扫描前显示文件数量、目录数量和占用空间，帮助确认目标是否正确。
- **注册表关联搜索**：搜索当前用户和本机范围内的 32 位、64 位注册表视图，识别安装位置、卸载命令、程序路径和其他直接路径引用。
- **证据分级**：把具有卸载位置或卸载命令等强证据的项目列为“确定垃圾”，把普通路径或程序标识引用列为“可疑”，并显示注册表路径、名称、数据和匹配原因。
- **人工确认**：扫描完成后候选项默认全选，用户可以逐项取消；只有选中的注册表项才会进入清理流程。
- **注册表备份**：清理前默认使用 Windows `reg.exe export` 导出选中的注册表键。备份文件直接放在 EXE 所在目录，文件名包含时间、目标目录和注册表信息。
- **强力删除**：普通删除遇到文件占用时，检测明确占用者，终止允许终止的相关进程后重试删除；必要时恢复 Windows Explorer。
- **后台扫描与进度**：注册表搜索和目录统计在后台执行，窗口不会因为大目录或大量注册表项而无响应；界面显示当前进度并支持取消扫描。

## 安全边界

清理工具涉及文件和注册表删除，因此 DevScout Cleaner 采用“扫描、展示、确认、清理”的流程，而不是静默猜测：

- 只处理用户输入并成功扫描的绝对路径，不接受相对路径。
- 拒绝磁盘根目录、Windows 目录、Program Files、用户目录以及 `C:\ProgramData` 本身等高风险目标。
- 注册表候选必须包含与目标目录相匹配的路径或程序引用，不会因为名称相似就递归删除整个注册表分支。
- 备份开关默认开启；关闭后仍可继续，但确认提示会明确说明不会生成 `.reg` 备份。
- 强力删除只处理 Windows Restart Manager 明确报告的占用进程，并保护系统核心进程、当前清理工具自身以及未被检测到的进程。
- 普通用户也可以扫描，但清理某些受保护文件或本机注册表项时可能需要以管理员身份运行。

注册表候选是基于证据的推断，不等同于系统官方的“软件清单”。建议在清理前检查候选项的完整路径、名称、数据和匹配原因，并保留备份。

## 工作原理

### 1. 建立目标特征

工具首先规范化用户输入的目录路径，并收集目录名、目录中的 `.exe` 文件名以及相关程序标识。这些特征用于后续匹配，避免只依赖一个容易变化的显示名称。

### 2. 并行搜索注册表

搜索器覆盖常见的卸载信息、`App Paths` 和 `Software` 分支，同时分别检查 32 位和 64 位注册表视图。它读取 `REG_SZ`、`REG_EXPAND_SZ`、`REG_MULTI_SZ` 等常见字符串类型，检查键名、值名称和值数据中的路径和程序引用。

搜索工作拆分为多个后台分支，并合并重复结果，因此大量注册表项不会阻塞 GUI。扫描过程中会报告已检查的注册表项数量，用户也可以取消当前任务。

### 3. 合并证据并分类

同一个注册表键可能同时命中安装位置、卸载命令和程序路径。工具会按根键、注册表视图和完整键路径去重，并合并匹配原因：

- **确定垃圾**：通常包含与目标目录直接匹配的安装位置、卸载命令或程序路径。
- **可疑**：包含一般路径引用、程序名称或其他较弱的关联信号，需要用户进一步确认。

这套分类只影响展示顺序和默认选择，不会绕过用户确认。

### 4. 备份后清理

清理前，工具先对用户选中的注册表键逐项导出备份，然后删除文件夹和注册表项。文件删除失败时，工具通过 Windows Restart Manager 获取占用进程，按保护规则结束相关进程后再次尝试。任何备份失败的注册表项都会跳过删除，避免在没有备份的情况下继续处理。

## 使用方法

1. 启动 `devscout-cleaner.exe`。
2. 将要处理的文件夹从 Windows 文件管理器拖入路径框，或输入绝对路径。
3. 点击“扫描”，等待目录统计和注册表候选完成。
4. 检查“确定垃圾”和“可疑”分组，确认每个注册表项的路径、名称、数据和匹配原因。
5. 保持“删除前备份注册表”开启，或根据需要取消；如有需要先打开备份目录。
6. 点击“删除并清理”，在确认对话框中启用强力删除后开始处理。

备份文件会直接生成在当前 EXE 所在目录。使用 Cargo 运行时，它们通常位于 `target\debug` 或 `target\release`；发布后的 EXE 放在哪里，备份文件就放在哪里。

## 构建

本项目面向 Windows，使用 Rust 2021 edition 和原生 Windows API。安装 Rust 后，在项目目录运行：

```powershell
cargo build --release
```

生成的程序位于：

```text
target\release\devscout-cleaner.exe
```

如果使用 GNU 工具链，请确保 MinGW linker 已加入 `PATH`。开发阶段可以运行：

```powershell
cargo run
```

建议在发布前执行：

```powershell
cargo fmt -- --check
cargo clippy --release -- -D warnings
cargo test --release
```

## 项目状态

DevScout Cleaner 目前专注于 Windows 本地软件目录和注册表残留清理。它不替代完整的系统备份工具，也不会承诺识别所有软件留下的每一条痕迹；对于不确定的候选项，应保留勾选状态以外的人工复核。
